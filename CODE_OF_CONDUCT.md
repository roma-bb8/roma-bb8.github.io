# Code of Conduct

This repository follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, be constructive, and no harassment or discrimination of any kind.

## Reporting

Report unacceptable behavior privately through the contact options on [roma-bb8.github.io](https://roma-bb8.github.io). Please do not open a public issue for it.
