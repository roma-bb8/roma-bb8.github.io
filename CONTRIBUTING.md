# Contributing

This repository only contains the **generated static site** of [roma-bb8.github.io](https://roma-bb8.github.io). It is produced automatically from a private project, so a pull request that edits files here cannot be merged: the next publish would overwrite it.

Useful contributions:

- Reporting a typo, a broken link, or a wrong fact on the site.
- Suggesting a better wording (English is not my first language).
- Reporting a barrier for people with disabilities. See the [Accessibility guidelines](./ACCESSIBILITY.md).

How to contribute:

1. Open an [issue](../../issues/new/choose) and name the page, for example `/blog/hello/`.
2. Quote the text or give the link, and say what you expect instead.

I apply accepted changes in the source and publish the site again. Please follow the [Code of Conduct](./CODE_OF_CONDUCT.md).
