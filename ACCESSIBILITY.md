# Accessibility

We want everyone, including people with disabilities and people who use assistive technology, to be able to read the site [roma-bb8.github.io](https://roma-bb8.github.io).

This repository contains only the generated site. This document explains what we aim for, what we know is not perfect yet, and how to tell us about a barrier.

## Priorities

- **Accessibility target:** we work toward [WCAG 2.2 Level AA](https://www.w3.org/TR/WCAG22). This is a goal, not a claim of verified conformance. No formal evaluation has been done.
- **Screen readers and keyboard:** pages use semantic HTML, so headings, lists, and links are real structure.
- **Readable content:** plain language, descriptive link text, and meaningful alternative text for images.
- **Languages:** the site is in English and Ukrainian, and each page is marked with its language.

## Known limitations

- Post preview images and the CV PDFs are generated, and the PDFs may be less accessible than the web pages. The same CV is available as a web page.
- English is not the author's first language, so wording may be unclear.

## Reporting accessibility issues

If you run into a barrier, please tell us. We treat accessibility reports as expertise, not complaints.

1. [Open an accessibility issue](../../issues/new?template=accessibility.yml).
2. If you can, include:
   - The page, and what you were trying to do and what went wrong.
   - Your operating system, browser, and assistive technology.

You do not need to share a diagnosis or any personal information. If you prefer not to use GitHub issues, use the contacts on the [site](https://roma-bb8.github.io).

This is a personal, volunteer project, so we cannot promise fixed response times.
